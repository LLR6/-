# LR—今日校园自动化签到

一个面向 Android 的个人操作自动化助手。目标是把“每天晚上重复打开今日校园、进入固定页面、走相同步骤”的机械操作录制下来，并在指定时间自动导航到签到确认页。

> 设计原则：不伪造定位、不绕过系统锁屏、不保存密码；检测到最终“签到/提交”动作时暂停，由本人确认。

## 当前功能

- 自动寻找并打开今日校园（默认包名 `com.wisedu.cpdaily`）
- 录制一次演示流程：点击 / 文本变更 / 滚动
- 回放时优先根据控件 ID、文字和无障碍节点识别页面
- 识别失败时按录制时的相对坐标回放
- 每日晚间定时任务（`AlarmManager.setExactAndAllowWhileIdle`）
- 锁屏/息屏时不尝试绕过锁屏：保存待执行状态，并发高优先级通知
- 可选短信提醒；短信权限或 ROM 不允许时自动降级到通知
- 解锁后自动继续待处理流程
- 遇到密码输入自动停止，不保存敏感输入
- 遇到“签到 / 提交 / 确认签到”等最终确认按钮自动暂停
- GitHub Actions 自动构建 debug APK

## 为什么不是直接改 CPDaily 接口

这类接口脚本极易受学校认证、验证码、接口升级和风控变化影响。本项目采用 Android 无障碍录制/回放思路，和 AutoJs6 的核心自动化理念一致，但做成了一个专用、轻量的原生 App，更适合做漂亮 UI、状态检测、锁屏提醒和容错。

AutoJs6：<https://github.com/SuperMonster003/AutoJs6>

## 使用

1. Android Studio 打开项目并安装 APK。
2. 第一次打开后，授予通知权限；如要用短信提醒，再单独授权短信权限。
3. 在系统“无障碍”设置中开启 **LR 今日校园自动化**。
4. 点击 **开始演示**，App 会打开今日校园。
5. 像平时一样走一遍签到路径；最后不要真正提交，返回 LR App 点击 **结束演示并保存**。
6. 点击 **测试回放** 验证路径。
7. 设置每晚时间并打开 **启用每日自动化**。
8. 如果到点手机锁屏/息屏，App 会保存任务并提醒；解锁后继续。

## 短信提醒说明

Android 的 `SEND_SMS` 是高敏感权限，部分 Android 版本、ROM 或安装渠道可能限制授权。因此短信提醒是“可选增强”，高优先级锁屏通知始终作为兜底。运营商也可能对短信计费。

同一台手机给自己的号码发短信是否能正常收到取决于运营商；推荐先在“测试”阶段确认。

## 安全边界

本项目只减少重复点击，不用于伪造实际到场、伪造 GPS、绕过人脸/照片/二维码验证或绕过系统锁屏。若学校把签到作为实际在场证明，最终提交必须由本人确认。

## AutoJs6 关系

本项目参考 AutoJs6 的 Android 无障碍自动化、脚本录制/回放和定时任务设计思路；为了降低 APK 体积和减少对大体量运行时的依赖，v0.1 使用原生 Kotlin 实现专用流程。后续可以增加 **AutoJs6 脚本导入/导出兼容层**，方便高级用户直接编辑脚本。
